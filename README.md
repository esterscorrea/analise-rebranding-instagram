# Análise de Rebranding no Instagram

Projeto de análise de dados desenvolvido em Python para avaliar o desempenho de conteúdos publicados durante diferentes fases de um processo de rebranding no Instagram.

## 🎯 Objetivo

Investigar como o desempenho das publicações variou entre as diferentes fases do rebranding e identificar padrões de engajamento relacionados ao formato, tema e tipo de conteúdo.

A análise busca transformar métricas de redes sociais em informações que possam apoiar decisões sobre estratégia de conteúdo.

## 🛠️ Tecnologias

* Python
* Pandas
* Matplotlib
* CSV
* Git/GitHub

## 📊 Dados analisados

O dataset contém informações sobre publicações do Instagram, incluindo métricas de engajamento e características dos conteúdos.

Foram analisadas variáveis relacionadas a:

* Fase do rebranding
* Formato da publicação
* Tema do conteúdo
* Colaboração
* Engajamento

## 🔎 Etapas da análise

1. Importação dos dados em formato CSV
2. Organização e tratamento do dataset
3. Agrupamento das publicações por diferentes características
4. Cálculo das médias de engajamento
5. Comparação entre categorias
6. Visualização dos resultados por meio de gráficos
7. Interpretação dos padrões encontrados

## 📈 Principais análises

O projeto compara o engajamento médio considerando diferentes dimensões:

* **Fase do rebranding**
* **Tipo de publicação**
* **Tema do conteúdo**
* **Colaboração**

Essas comparações permitem identificar quais características estiveram associadas aos melhores resultados de engajamento no período analisado.
